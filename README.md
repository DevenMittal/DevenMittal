I work on machine learning for particle tracking at **Lawrence Berkeley National Laboratory**, with the ATLAS Computing group. I develop and benchmark distance-based graph neural network edge filters in GNN4ITk / ACORN.

Previously, I was a **machine learning intern at DoorDash**, working on the Optimal Tips model. I’ve also worked on Kubernetes monitoring, audio classification, and embedded voice-command models.
